# Spec Delta

## Purpose

保护管理后台（题库维护、面试人员管理）不被未授权访问：管理员使用环境变量中配置的单一密码登录，获得有时效的会话凭证后才能调用后台管理接口。

## ADDED Requirements

### Requirement: 管理员密码登录
系统 SHALL 提供管理员登录接口，校验提交的密码与环境变量配置的管理员密码一致后，签发有时效的 JWT 会话凭证；密码不一致时 MUST 拒绝登录且不泄露任何密码信息。

#### Scenario: 登录成功
- **WHEN** 管理员在登录页提交正确的密码
- **THEN** 系统返回 JWT 凭证并跳转到面试人员列表页

#### Scenario: 密码错误
- **WHEN** 管理员提交错误的密码
- **THEN** 系统返回 401 与统一的"密码错误"提示，不签发凭证

### Requirement: 后台接口鉴权
所有后台管理接口（题库 CRUD、面试人员创建/列表/明细）MUST 校验请求携带有效且未过期的 JWT；无效、缺失或过期的凭证 SHALL 返回 401。候选人考试相关接口不使用该鉴权。

#### Scenario: 携带有效凭证访问
- **WHEN** 请求携带有效 JWT 调用后台管理接口
- **THEN** 接口正常处理并返回数据

#### Scenario: 未登录访问
- **WHEN** 请求未携带凭证或凭证已过期
- **THEN** 接口返回 401，前端管理页跳转到登录页
