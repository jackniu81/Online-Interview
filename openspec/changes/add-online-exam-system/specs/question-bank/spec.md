# Spec Delta

## Purpose

维护在线笔试使用的主观题题库：每道题包含题目内容与参考答案，支持管理员增删改查，并在系统初始化时预置 30 道 AI agent 相关题目供考试抽取。

## ADDED Requirements

### Requirement: 主观题维护
系统 SHALL 允许已登录管理员对题库进行增删改查；每道题 MUST 包含题目内容（支持 Markdown/代码块）与参考答案两个必填字段，题目内容或参考答案为空时 MUST 拒绝保存。

#### Scenario: 新建题目
- **WHEN** 管理员填写题目内容与参考答案并保存
- **THEN** 题目入库并出现在题库列表中

#### Scenario: 编辑与删除题目
- **WHEN** 管理员修改已有题目内容或删除某题
- **THEN** 题库列表反映修改结果；已被考试抽取的题目不受影响（考试持有题目快照）

#### Scenario: 必填校验
- **WHEN** 管理员提交缺少题目内容或参考答案的题目
- **THEN** 系统返回校验错误，不入库

### Requirement: 题库列表
系统 SHALL 提供分页的题库列表，展示题目摘要与创建时间，并支持按关键字搜索题目内容。

#### Scenario: 查看题库
- **WHEN** 管理员进入题库页面
- **THEN** 系统按创建时间倒序分页展示题目

### Requirement: 初始化 30 道 AI agent 题目
系统 SHALL 在数据库初始化（种子数据）时预置 30 道与 AI agent 相关的主观题，每题均含题目与参考答案；重复执行初始化 MUST NOT 产生重复题目。

#### Scenario: 首次初始化
- **WHEN** 对空题库执行初始化命令
- **THEN** 题库中存在 30 道 AI agent 相关题目，均含参考答案

#### Scenario: 重复初始化
- **WHEN** 再次执行初始化命令
- **THEN** 题目总数保持不变，不产生重复
